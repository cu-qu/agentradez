# Product growth

Notes on acquisition, activation, retention, and monetization.

Suggested filename: `YYYY-MM-DD-topic.md`

Pull the automated daily digest from the API and drop it here:

```bash
curl -H "X-Metrics-Key: $METRICS_API_KEY" \
  "$API_URL/api/metrics/digest/"
```

Save as `YYYY-MM-DD-digest.md` using the `summary_markdown` field. The API covers new users, revenue, and substantial model additions.

Examples: launch checklist, pricing experiment, onboarding funnel, referral idea,
waitlist copy, Stripe conversion notes.
