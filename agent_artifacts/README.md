# Agent artifacts

This folder is the product's working memory for agents and humans. Do not put
secrets here. Do not put source code here.

| Folder | Put here |
|---|---|
| `agent_outputs/` | Agent run notes, implementation summaries, research dumps |
| `pr_qa_plans/` | PR test plans and QA checklists |
| `issue_recording/` | Bug write-ups, reproduction notes, incident logs |
| `product_growth/` | Experiments, funnel notes, launch checklists, metrics |
| `product_improvements/` | Backlog, postmortems, issue resolutions, follow-ups |

Name files with a date prefix: `2026-08-22-short-title.md`.
